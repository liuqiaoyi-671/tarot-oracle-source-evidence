# Tarot Oracle · 塔罗神谕

这是个人塔罗网站项目的**选定源码公开快照**，由项目维护者整理发布，供代码查阅与项目开发情况核对。

网站由本人主导制作，使用 AI 辅助编程，并持续修改与维护。网站支持牌阵、牌面选择、AI解读、账号、历史与额度功能；并非所有使用方式都免费。自备 API Key 时，现有代码路径不额外扣取本站付费额度，第三方服务商可能收费；本站提供的 AI 通道另有免费额度、付费次数包和月会员。

## 本次公开的范围

- 前端 HTML、CSS、JavaScript；主要入口为 `index.html`、`app.js`。
- Cloudflare Pages Functions、计费及认证业务模块、数据库结构与迁移。
- 构建脚本及自动化测试。
- `source-manifest.json` 记录本次选定原始源码的 SHA-256，可与本地源文件核对。

图片、字体、参考书、学习文章源数据、生产配置与所有私有运营记录未包含在本快照中。因此这不是包含全部运行资源的一键部署包；构建脚本仍引用原项目中未公开的资源。
